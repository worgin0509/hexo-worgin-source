实习第二周学习笔记

  1. SwithyOmega
    SwitchyOmega 是一个浏览器代理管理插件，能够自动切换我的vps和网络直联。
    插件根据你预设的规则列表，自动判断你访问的每一个网站请求应该走哪条网络通道。
    比如访问的网站（如Google、GitHub）在“被屏蔽”或“需要代理”的列表里，浏览器会自动将请求转发到我配置的代理服务器，由它帮我获取内容，实现“翻墙”。
    如果访问的是国内网站（如百度、知乎），请求则直接连接，不经过代理，保证访问速度。
    操作步骤：
    第一步：安装插件
    在 Chrome 网上应用店或 Firefox 附加组件站中搜索 “SwitchyOmega” 并安装。
    第二步：配置代理情景模式
    点击浏览器右上角的 SwitchyOmega 图标，选择 “选项”。
    点击 “新建情景模式”，类型选 “代理服务器”，命名为（例如Proxy
    在 Proxy模式中，填写你拥有的代理服务器信息：
    协议：根据你的节点类型选择（如 SOCKS5、HTTP）。
    服务器：你的代理服务器地址。
    端口：对应的端口号。
    填写用户名和密码。
    点击 “应用选项” 保存。
    第三步：配置自动切换模式
    再次 “新建情景模式”，类型选择 “自动切换模式”，命名为AutoSwitch。
    在 “切换规则” 选项卡下：
    默认情景：选择 “直接连接”（即不走代理）。
    规则列表规则：点击“添加规则列表”，在规则集网址处填入一个公开的GFW列表，情景选择你刚才创建的 
    点击 “应用选项” 保存。
    第四步：启用与使用
    在浏览器右上角的 SwitchyOmega 图标上点击，选择你刚刚创建的模式 
    AutoSwitch
    作为当前情景。
    此时，当你访问任何网站，插件便会自动根据规则列表判断：匹配列表的（国外受限网站）走 
    Proxy
     代理，不匹配的（国内网站）则“直接连接”。
  2. venv
    venv是Python官方推荐的轻量级虚拟环境管理工具。其核心原理是：通过复制一份独立的Python解释器和包目录，为每个项目创建隔离的“沙箱”环境，从而解决项目间依赖冲突的难题。
    简单来说，就像为每个项目建立一个独立的“工具箱”。当你在项目A的工具箱里安装或升级螺丝刀（某个依赖包）时，完全不会影响项目B工具箱里的工具。
  3. Trae+ssh远程开发
    Trae + SSH 实现本地远程开发是基于 安全的加密通信通道 和 远程资源映射技术 ，让开发者能够在本地 Trae AI IDE 中编辑、运行和调试存储在 Ubuntu 服务器上的代码。其本质就是 “远程开发主机”模式。原理上，它通过 SSH 隧道将远程服务器的完整开发环境“投射”到你的本地 IDE 中。
    工作流程示例
    连接建立 ：
    Trae IDE 通过 SSH 协议连接到 Ubuntu 服务器
    进行身份验证（通常使用 SSH 密钥对）
    文件访问 ：
    你在 Trae IDE 中打开 /home/ubuntu/dify/api/app.py
    Trae 通过 SSH 从远程服务器获取该文件的内容
    文件内容在本地 Trae IDE 中显示
    代码编辑 ：
    你修改了 app.py 中的端口配置
    Trae 实时通过 SSH 将更改同步到远程服务器上的 app.py 文件
    运行代码 ：
    你在 Trae IDE 的终端中执行 python app.py
    该命令通过 SSH 转发到远程服务器执行
    服务器上的 Python 解释器运行代码
    运行输出通过 SSH 加密传输回 Trae IDE 显示
